# Plan: Upgrade cesium 1.128 and resium 1.19.0-beta.1, vite 6.3 advisories (issue #10)

Risk tier: High. The issue is labeled `security` and the change replaces the libraries
that ship to users' browsers (Cesium's bundled `dompurify` sanitizes credit HTML), so the
force-High security rule applies. Rendering (WebGL globe, terrain, InfoBox, timeline)
cannot be exercised by the jsdom unit suite and needs a live drive.

  notes if anything in the gate breaks.
- chrome-devtools-mcp:chrome-devtools (or claude-in-chrome): invoke for the live drive.

## Acceptance criteria

1. `npm audit --omit=dev` reports no high or critical vulnerabilities (and the CI `audit`
   job, `npm audit --omit=dev --audit-level=high`, passes unchanged).
2. No pre-release versions in `package.json` `dependencies` (no `-alpha`, `-beta`, `-rc`
   or other `-` suffix), enforced by a unit test.
3. `cesium` is the latest stable 1.x (1.147.0 at time of writing) and `resium` the latest
   stable (1.28.0). Every Cesium breaking change between 1.128 and 1.147 is checked
   against the APIs `src/` uses (see Risks); any that applies is handled.
4. `vite` is upgraded to a 6.x release with no open advisories (6.4.5, the smallest
   upgrade that clears them and satisfies Vitest 4's `vite >= 6.4` peer). No major upgrade
   of vite, `@vitejs/plugin-react`, eslint or TypeScript.
5. `vitest` is upgraded to >= 4.1.12, and full `npm audit` (dev included) reports no
   critical vulnerabilities. Dev-only transitive advisories are cleared with plain
   `npm audit fix` (no `--force`), lockfile only.
6. The app builds and runs with the upgraded Cesium and Resium: globe, terrain, quake
   entities, InfoBox popup on entity click, filter panel and timeline/animation widgets
   render in `npm run dev` and in `npm run build && npm run preview`, with no console
   errors attributable to the upgrade.
7. `.github/dependabot.yml` is committed: `npm` (directory `/`) and `github-actions`
   (directory `/`) ecosystems, `weekly` schedule, each with a group that collects
   `minor` and `patch` updates into one PR. No paid services.
8. Gates pass in order: `npm ci`, `npm run lint`, `npx tsc -b`, `npm test`,
   `npm run build`, `npm audit --omit=dev --audit-level=high`. The CI workflow is not
   modified.

## Risks

- Cesium breaking changes 1.129 to 1.147 (from `node_modules/cesium/CHANGES.md`): voxel
  and custom shader changes, `ClippingPolygon` immutability, Buffer*Collection
  properties, `defaultValue` removal (1.134), `Cartesian3` becoming an ES6 class so
  `new Cartesian3.fromDegrees(...)` throws (1.139), Node >= 22 (1.141), billboards and
  labels needing WebGL2 or instanced arrays (1.140), `drillPick` order (1.135). `src/`
  uses none of the removed APIs: `Cartesian3.fromDegrees` is called without `new`;
  `Clock`, `ClockViewModel`, `JulianDate` are used as constructors. The implementer
  re-greps `src/` for `new [A-Z][A-Za-z]*\.from` and `defaultValue` to confirm.
- Resium 1.19 beta to 1.28: `Viewer` props (`full`, `terrainProvider`, `clockViewModel`,
  `timeline`, `animation`) and `Entity` props (`cylinder`, `description`) must still be
  accepted; `npx tsc -b` catches type changes, the live drive catches runtime ones.
- Vitest 4: config keys moved or removed in 4.0 (e.g. pool options); the current config
  uses only `environment` and `setupFiles`. `@testing-library/jest-dom/vitest` must still
  register matchers.
- `npm audit fix` rewrites many transitive dev versions in the lockfile; the gate and the
  `setup` matrix in CI (Ubuntu, macOS, Windows) prove they still work.
- Bundle size: the Cesium chunk stays well over 500 kB (existing warning, unchanged in
  kind); not in scope.
- Not doing: vite 7/8, `@vitejs/plugin-react` 5/6, eslint 10, TypeScript 6/7, vitest 5.
  Remaining moderate dev advisories under `typescript-eslint` are not required by the
  criteria and are left for Dependabot.
- No `VITE_CESIUM_ION_TOKEN` is available in the main checkout (no `.env`). Without a
  token, Cesium ion terrain and the default ion imagery cannot load; the live drive must
  say exactly what was and was not verified.
